# Advance---Calc
A modern and responsive calculator built using HTML, CSS, and JavaScript.

# Features

1. Basic arithmetic operations
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - Percentage

2. Calculation History
3. Auto-clear after calculation
4. Delete button
5.  Modern UI Design
6. Responsive layout
7. Clean and user-friendly interface

# Technologies Used

- HTML5
- CSS3
- JavaScript
